MISSION 08 PROJECT

1. Extract mission-08.zip.
2. In VS Code choose File > Open Folder and select the extracted mission-08 folder.
3. Open the VS Code terminal (Terminal > New Terminal).
4. Check Python: python --version
5. Run each module:
   python rewoo_planner.py
   python reflexion_surgeon.py
   python memgpt_pager.py
   python sandbox_guardian.py

The project uses only the Python standard library. Read mission-08-doc.md for implementation notes.
Important: sandbox_guardian.py is a static checker, not a secure sandbox. Do not execute untrusted code.
